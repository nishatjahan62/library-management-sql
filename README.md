# 📚 Library Management SQL

A hands-on PostgreSQL project for building and querying a fully structured library management system — covering everything from schema design to advanced filtering and functions.

---

## 🗂️ Topics Covered

-  Database & table creation
-  Data insertion (single, multiple, default ID)
-  ALTER operations (add/drop/rename columns, constraints)
-  SELECT & filtering (WHERE, AND, OR, BETWEEN, IN)
-  Pattern matching with LIKE & ILIKE
-  Scalar functions (UPPER, LOWER, CONCAT, LENGTH)
-  Aggregate functions (AVG, MAX, MIN, SUM, COUNT)

---

## 🗃️ Files

| File | Description |
|------|-------------|
| `Creations & Insertions.sql` | Table schema and all book records |
| `Alter.sql` | Table structure modifications |
| `Select.sql` | Queries, filters and sorting |
| `Like_ILike.sql` | Pattern matching queries |
| `Function.sql` | Scalar and aggregate functions |

---

## 🛠️ Tech Stack

-  PostgreSQL 18
-  Beekeeper Studio
